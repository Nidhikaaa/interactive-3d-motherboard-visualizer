# Interactive 3D Motherboard Explorer

An interactive 3D motherboard visualization built using HTML, CSS, JavaScript and Three.js.

## Features
- Interactive 3D motherboard model
- Rotate and zoom using mouse controls
- Click individual motherboard components to explore them
- View component names, functions and connections
- Search for specific components
- Animated circuit pathways and visual effects
- Responsive interface

## Technologies Used
- HTML5
- CSS3
- JavaScript
- Three.js
- OrbitControls

## Purpose
This project is designed to make learning computer hardware easier through an interactive 3D visualization of motherboard components and their functions.
